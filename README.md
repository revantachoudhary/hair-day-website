# Hair Day

A single-page static website for **Hair Day**, a fictional boutique hair salon specializing in cutting, coloring, and styling services.

This project was developed as part of the **Meta Front-End Developer Professional Certificate** coursework and demonstrates fundamental frontend development using HTML5 and CSS3.

## Live Demo

🌐 [View Hair Day Website](https://revantachoudhary.github.io/hair-day-website/)

## Overview

The website presents Hair Day's services through a visually styled single-page layout with custom branding, navigation, imagery, typography, and interactive hover effects.

The project focuses on practicing the structure and presentation of a frontend website using semantic HTML and CSS, with a Flexbox-based layout.

## Features

* Single-page salon website
* Navigation using internal page anchors
* Hero/banner section
* Service sections for:

  * Haircuts
  * Hair Coloring
  * Hair Styling
* Custom branding and imagery
* Flexbox-based page layout
* Interactive hover effects
* Custom typography using Google Fonts
* Semantic HTML structure
* Image `alt` text for accessibility
* Favicon and basic website metadata

## Technologies

* **HTML5**
* **CSS3**
* **Flexbox**
* **Google Fonts**

## Project Structure

```text
hair-day-website/
│
├── index.html
├── style.css
│
└── assets/
    └── images/
        ├── banner.jpg
        ├── color.webp
        ├── cut.jpg
        ├── logo0.png
        ├── styling.webp
        └── title1.png
```

### `index.html`

Contains the structure and content of the Hair Day website, including the header, navigation, service sections, and footer.

### `style.css`

Contains the website's visual styling, typography, colors, Flexbox layouts, borders, spacing, and interactive hover effects.

### `assets/images/`

Contains the images and branding assets used throughout the website.
